# Capydoku 🍊

광고 없는 카피바라 두뇌 퍼즐. iPhone 홈 화면에 추가하면 앱처럼 전체 화면으로 열리고, 한 번 열어두면 오프라인에서도 플레이할 수 있습니다.

정적 파일만으로 동작하는 순수 클라이언트 웹앱이라 GitHub Pages 어디에나 그대로 올릴 수 있습니다.

## 규칙

카피바라를 다음 조건에 맞게 놓으면 됩니다.

- 모든 **가로줄**에 카피바라가 정확히 한 마리
- 모든 **세로줄**에 정확히 한 마리
- 같은 **색 구역**에 정확히 한 마리
- 카피바라끼리 **맞닿을 수 없음** — 위아래, 좌우는 물론 대각선도 안 됩니다

모든 퍼즐은 정답이 **단 하나**뿐임을 생성 단계에서 solver로 검증합니다.

## 레벨

| 묶음 | 레벨 | 크기 | 설명 |
| --- | --- | --- | --- |
| 쉬운 레벨 | 초급 | 5×5 | 입문·어린이 추천 |
| 쉬운 레벨 | 쉬움 | 6×6 | 한 걸음 더 |
| 어려운 레벨 | 보통 | 7×7 | 도전 시작 |
| 어려운 레벨 | 어려움 | 8×8 | 집중 필요 |
| 어려운 레벨 | 전문가 | 9×9 | 고수용 |
| 어려운 레벨 | 마스터 | 10×10 | 최고 난도 |

- **새 퍼즐**: 같은 레벨에서 무제한으로 새 퍼즐을 만듭니다.
- **오늘의 퍼즐**: 서울 날짜(YYYY-MM-DD)로 시드가 정해져 매일 새 퍼즐이 열립니다. 어느 레벨에서든 데일리 퍼즐을 즐길 수 있습니다.
- 8×8 이상은 2칸짜리 구역이 거의 없도록 구역 크기를 균형 있게 다듬어, 한 칸짜리 구역으로 쉽게 풀리는 일을 막습니다.

## 플레이 기능

- **입력 방식**: `자동 순환`, `✕ 메모`, `카피바라` 중 선택
- **자동 순환**: 빈칸을 한 번 누르면 ✕가 표시되고, ✕를 다시 한 번 누르면(잠시 뒤) 귤 차감 없이 지워집니다. 같은 칸을 두 번 빠르게 누르면(0.35초 안) 카피바라를 놓는 시도입니다 — 정답 칸이면 카피바라가 놓이고, 아니면 귤이 하나 줄고 칸은 빈칸으로 돌아갑니다(빨간 표시와 안내 문구)
- **카피바라**: 한 번 누르면 카피바라를 놓는 시도입니다(틀리면 귤 -1). 놓인 카피바라는 한 번 눌러 지웁니다
- **✕ 메모**: 누르거나 끌어서 빈칸 ↔ ✕를 바꿉니다. 귤은 줄지 않습니다
- **드래그 메모**: 빈칸에서 손가락을 끌면 지나간 칸에 ✕가 그려지고, ✕가 있는 칸에서 끌면 지나간 칸의 ✕가 지워집니다
- **자동 메모**: 기본은 꺼짐. 설정에서 켜면 이미 놓인 카피바라 때문에 막힌 칸에 흐린 ✕를 자동 표시합니다. 지운 칸에는 다시 표시하지 않습니다
- **귤 3개**: 규칙에 어긋나는 칸을 누르면 귤이 하나 줄고, 잘못 놓인 카피바라는 보드에 남지 않습니다. 귤을 모두 쓰면 광고 없이 바로 3개를 충전하거나 처음부터 다시 시작할 수 있습니다
- **완성 축하**: 퍼즐을 다 맞히면 보드 네모 주변으로 색색의 꽃가루가 터지며 축하합니다
- **되돌리기 / 힌트 / 다시 시작**과 타이머
- **다크 모드**, **색약 대비 패턴**(구역마다 도트·사선·격자 무늬)
- **카피바라 도감**: 헤더의 🏆 버튼으로 열고, 모은 카피바라를 눌러 바로 장착합니다. 장착한 모습은 보드·상단 배지·`카피바라` 버튼·완성 화면에 함께 바뀝니다
- 진행 상황, 데일리 연속 일수, 클리어 수, 난이도별 최고 기록을 기기에 저장

## 카피바라 도감

퍼즐을 풀다 보면 카피바라 친구들이 하나씩 모입니다. 모두 10종이고, 헤더의 🏆 버튼에 모은 수(`3/10`)가 표시됩니다. 도감에서 해금한 카피바라는 눌러서 바로 장착할 수 있고, 새로 해금되면 완성 화면에서 `바로 쓰기` / `도감에서 보기`를 고를 수 있습니다.

| 카피바라 | 해금 조건 |
| --- | --- |
| 기본 귤 카피바라 | 처음부터 함께 |
| 수건 온천 카피바라 | 누적 3판 클리어 |
| 핑크 리본 카피바라 | 누적 6판 클리어 |
| 딸기 카피바라 | 누적 10판 클리어 |
| 선글라스 쿨바라 | 실수 없이 1판 클리어 (귤을 하나도 잃지 않고) |
| 네잎클로버 카피바라 | 오늘의 퍼즐 3일 클리어 |
| 꿀잠 수면모자 카피바라 | 한 판 10분 넘게 집중해 클리어 |
| 별빛 마법 카피바라 | 누적 25판 클리어 |
| 왕관 마스터바라 | 어려운 레벨(7×7 이상) 3판 클리어 |
| 무지개 전설 카피바라 | 카피바라 9종을 모두 모으면 |

해금 기록과 장착한 카피바라는 `localStorage`의 `capydoku.stats.v1`(`skins.unlocked`, `skins.active`)에 함께 저장됩니다. 설정의 `기록 초기화`는 클리어 수·최고 기록을 지우지만 도감은 그대로 남깁니다.

## 설치와 배포

### GitHub Pages

1. 이 폴더의 파일을 저장소 루트에 올립니다.
2. 저장소 **Settings → Pages**에서 브랜치와 `/ (root)`를 선택합니다.
3. `https://<계정>.github.io/<저장소>/` 로 접속합니다.

모든 경로가 상대 경로(`./`)라 하위 경로에 배포해도 그대로 동작합니다.

파일을 수정해 다시 배포할 때는 세 곳의 버전을 함께 올려 주세요.

1. `sw.js`의 `VERSION`(예: `5` → `6`) — 캐시 이름이 `capydoku-v6`이 되고 이전 캐시는 지워집니다.
2. `index.html`의 `?v=` (예: `styles.css?v=5` → `?v=6`, `app.js?v=5`, `engine.js?v=5`) — 예전 서비스 워커의 캐시를 건너뛰게 합니다.

서비스 워커는 화면·스타일·스크립트를 네트워크 우선으로 받아오므로, 인터넷이 연결된 상태에서 새로고침하면 항상 최신 파일이 열립니다. 네트워크가 없을 때만 캐시로 동작합니다.

### iPhone 홈 화면

Safari에서 주소를 연 뒤 **공유 → 홈 화면에 추가**를 누르면 standalone 앱으로 열립니다.

## 개발

```bash
# 퍼즐 엔진 테스트 (5×5 ~ 10×10 고유해 검증, 성능 측정)
node --test test/engine.test.js

# 모바일 UI 테스트 (390×844) + 스크린샷
node test/ui.test.mjs

# 폴백 퍼즐 풀 재생성 (engine.js 안의 FALLBACK_POOL 갱신)
node scripts/build-pool.js
```

UI 테스트는 Playwright와 Chromium이 필요합니다. 저장소에 포함된 스크립트는 워크스페이스의 Playwright를 사용하고, 없으면 `playwright` 패키지를 찾습니다.

### 폴더 구조

```
index.html      화면 마크업
styles.css      iPhone 우선 스타일, 다크 모드, 구역 패턴
app.js          입력, 타이머, 귤, 저장, 설정
engine.js       퍼즐 생성기 + solver (브라우저/Node 공용)
manifest.json   PWA 매니페스트
sw.js           오프라인 서비스 워커
icons/          apple-touch-icon 180, 192, 512 아이콘
test/           엔진 단위 테스트, 모바일 UI 테스트
scripts/        폴백 퍼즐 풀 빌드 스크립트
```

## 개인정보

- 광고, 추적, 분석 도구가 없습니다.
- 서버가 없습니다. 퍼즐은 모두 기기 안에서 생성됩니다.
- 저장되는 것은 브라우저 `localStorage`의 진행 상황·설정·기록뿐이며, 밖으로 전송되지 않습니다.
